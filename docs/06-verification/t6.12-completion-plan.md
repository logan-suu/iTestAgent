## 当前公开来源核查

- Xcode 本机公开 `Xcode.sdef` 暴露 workspace document、documents 集合、file/path 和 run destination；workspace document 未提供已核实的永久实例 ID。它不能直接替代原窗口/原文档连续性。
- [Apple NSRunningApplication](https://developer.apple.com/documentation/appkit/nsrunningapplication) 要求主 run loop 推进以刷新动态状态；正常退出请求不等于已经退出。
- [Apple NSApplication terminate](https://developer.apple.com/documentation/appkit/nsapplication/terminate(_:)) 说明文档及 delegate 可以取消或延迟退出。不能把请求返回视为完整资源关闭。
- [LLDB SBPlatform](https://lldb.llvm.org/python_api/lldb.SBPlatform.html) 的 GetHostname 不提供已经核实的物理 UDID 语义；LLDB 唯一进程实例仍需与设备/构建链实际关联。

这些核查只支持实现约束，不构成新增宿主或设备验证。
