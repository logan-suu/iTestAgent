# Evidence Provenance

Captured evidence for migration verification (promotion guide §11.3
"verification-missing" — verified elsewhere in the batch tree, §12.3).

- `t12/universal/` — TUI universal test run evidence: manifest, result,
  summary, artifact index and a captured TUI frame (ANSI).
- `t13/renderer-matrix/` — renderer cross-evaluation evidence: ansi / ink /
  opentui frame captures, outcomes comparison and manifest.

`SHA256SUMS` pins the integrity of every evidence file.
